# Travel Fare Calculator

## Description
This program calculates travel fares.

## Version 1 - Original Code With Input Validation
- Input: Accepts a user's name, distance from destination, and amount of passengers.
  
- Process: Calculates and displays the total travel fare.
  
- Output: Travel fare.
  
- Input Validation: Passenger name can't be empty, distance must be greater than 0, and passenger number must be a positive whole number.
